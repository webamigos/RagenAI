# Published runs

Results of `npm run eval:benchmark -- --profile default` — the default install
and nothing else, checked before and during the run. These are the figures a
release may quote; everything else in `results/` is an experiment.

Each release adds three runs per corpus (`docs/regression-checklist.md`,
"Retrieval quality"). Quote the median, with its control column and the method
in [`../../README.md`](../../README.md#method-for-anyone-quoting-it).
