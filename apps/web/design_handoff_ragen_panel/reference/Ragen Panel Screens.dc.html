Conversation with sources

Retrieval is stated, not hidden: one summarising row, inline markers, and a sources rail you can pin.
Q3 payroll masking policy · HR assistant
Which masking policy applies to the Q3 payroll file, and does the model see the original PESEL?
JD
Searched 3 documents · 12 chunks · 240 ms

The Q3 payroll file sits in the HR / Payroll folder, which is set to All personal data — PESEL, ID numbers, IBANs, plus emails, phone numbers, names and locations are masked before storage1.

The organization runs Secure ingestion, so the answer is no: the original PESEL is irreversibly replaced and never persisted, and no encrypted copy passes to the model2. Extended mode would change that, and it is off3.
